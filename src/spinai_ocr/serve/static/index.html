Quick Start

API (curl)

curl -X POST https://spinai-ocr-production.up.railway.app/ocr \
  -F "file=@photo.jpg"

Python

from spinai_ocr import OCRPipeline
pipe = OCRPipeline(lang="ko")
result = pipe("photo.jpg")
print(result.lines[0].text)

Docker

docker run -p 8080:8080 spinai/ocr:latest
# Then: curl localhost:8080/ocr -F file=@img.jpg
